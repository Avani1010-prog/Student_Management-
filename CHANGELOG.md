# Changelog

All notable changes to CAMP ERP will be documented in this file.

---

## v1.0 (Node.js & Express ERP Edition)

### Added & Migrated
- **Node.js & Express Backend Conversion**: Fully migrated backend engine from Python/Flask to Node.js & Express.
- **EJS Rendering Engine**: Converted Jinja2 templates to EJS while retaining 100% Bootstrap 5 responsiveness & styling.
- **SQLite3 Integration**: Implemented high-performance `better-sqlite3` driver with WAL journaling.
- **Subject & Department Management (v0.7)**: Added HOD management, course subjects, credits, and department code routing.
- **Attendance Management (v0.8 & v0.9)**: Added manual attendance logging, status tracking, and AI Face Recognition Python spawn bridge.
- **QR Code Verification System (v0.9)**: Added dynamic session QR token generation and live verification scan API.
- **Reports & CSV Analytics (v1.0)**: Added institution statistics overview and instant CSV export generator.
